# Imersão CIT · Frinape 2026

Proposta em duas abas: estrutura e tecnologia; desenvolvimento do conteúdo imersivo.

- Endereço público: https://www.delumo.com.br/imersao
- Entrada: `index.html`, com base `/imersao/` para resolver os recursos com ou sem barra final.
- Publicação: o build principal inclui esta pasta via `scripts/package-site.mjs`.
- Identidade: logotipo, fonte Bricolage Grotesque, verde `#a8ff0a` e animação do rodapé do site Delumo.
- Vídeo: arquivo fornecido reproduzido diretamente em HTML5; referência original preservada em https://youtu.be/yThs0m4xK8c. O player direto evita a incorporação vazia observada no navegador.
- Imagens: arquivos fornecidos, preservados com `object-fit: contain`.

Os valores dos serviços continuam “A definir”. Custos de equipamentos são estimativas recebidas. Lotação, instalação e adequação dos equipamentos dependem dos testes indicados na proposta.

Validação: build do site, 11 testes de regressão, navegação entre abas, vídeo, pausa ao trocar de aba, rodapé animado e layout em desktop/celular.
